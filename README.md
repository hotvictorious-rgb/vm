# Victorious MARKET

Victorious MARKET is a multi-vendor e-commerce platform designed and optimized for local trade in Uyo, Nigeria. The platform consists of a Laravel web administration backend and three native Flutter mobile applications (Customer, Vendor, and Delivery).

## 📁 Repository Structure

*   **`backend/`**: Laravel Admin Panel, Vendor Panel, API services, and Storefront web layouts.
*   **`User app/`**: Flutter mobile application for customers (browsing, purchase, tracking).
*   **`Vendor app/`**: Flutter mobile application for store owners to manage products and orders.
*   **`Delivery Man App/`**: Flutter mobile application for dispatch riders to accept jobs and verify deliveries.

---

## 🚀 Deployment Guide

### 1. Web & Backend Installation (cPanel / Server)
1.  Compress the contents inside the `backend/` folder on your local computer into a ZIP file.
2.  Upload and extract the ZIP file in your cPanel site directory (e.g., `/public_html/shop.victoriousmarket.com.ng`).
3.  Create a MySQL database and user in your cPanel.
4.  Open `https://shop.victoriousmarket.com.ng` in a browser and follow the installation wizard.
5.  *Note:* The activation class is locally bypassed; you can enter any purchase key (e.g., `12345678-abcd-1234-abcd-1234567890ab`) to complete the setup.

### 2. Third-Party Integrations (Admin Panel)
*   **Payments:** Configure Paystack and Flutterwave under **3rd Party Setup -> Payment Methods** using your live API credentials. Setup your bank details under **Offline Payment Methods**.
*   **Notifications (Firebase):** Download the private service account key `.json` from your Firebase Console and upload it under **3rd Party Setup -> Firebase Configuration**.
*   **Google Sign-In:** Create a project in Google Cloud Console, register your web application, add authorized redirect URIs, and copy the Client ID and Client Secret Key to the dashboard under **3rd Party Setup -> Other Configuration (Social Login)**.

## 🛠️ Automated Mobile App Builds

We have integrated **GitHub Actions** for automated cloud compilation. Every time you push to the `master` branch (or run manually from the **Actions** tab on GitHub), the cloud virtual machines will compile:
1.  **APK files (`.apk`)**: For direct download, testing, and manual installation on Android devices.
2.  **App Bundles (`.aab`)**: The secure, optimized package required for uploads to the Google Play Store.

## 🔒 Security Protections

Victorious MARKET uses state-of-the-art security features to protect your data, financial transactions, and user accounts:
1.  **Code Obfuscation:** The Flutter applications are compiled directly into native ARM binary code. This makes it extremely difficult for hackers to reverse-engineer or view your source code.
2.  **HTTPS Encryption:** All communications between the mobile apps, the web store, and the database are encrypted using SSL (HTTPS).
3.  **Delivery Verification OTP:** Each order requires a secure verification code generated by the customer app to be entered by the delivery rider to prevent fraudulent deliveries.
4.  **SQL Injection Protection:** The backend uses Laravel Eloquent ORM to sanitize all database inputs automatically.
5.  **CSRF Protections:** Protects your admin panel and storefront from cross-site request forgery attacks.
